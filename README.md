Bank Management & ATM System (C++ Project)

This is a C++ console application that simulates a bank management system with two modes of operation:

Bank Mode (Admin/User):

Add, update, delete, and find clients

Manage users with bitwise access permissions

Perform transactions (deposit, withdraw, balances)

ATM Mode (Client):

Secure login with account number & PIN

Show balance, quick withdraw, deposit, withdraw

Key Features:

File handling with .txt storage (persistent data).

Object-oriented design with structs & modular functions.

Role-based access using bitwise permissions.

Transactions and account management.

Clean tabular display using iomanip.

Technologies Used:

C++ (file handling, bitwise operations).

Standard Used Library (iostream, fstream, vector, string, iomanip).
